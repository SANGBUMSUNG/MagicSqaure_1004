## 1. 개요

### 1.1 한 줄 정의

4×4 격자에서 **빈칸 2곳(0)** 을 찾아 1~16 중 남은 숫자를 넣고, **행·열·대각선 합이 모두 34**인지 판정·완성하는 학습용 마방진 도구.

### 1.2 배경

- **과제:** 소프트웨어 설계 연습 — ECB 분류 및 문제인식 실패조건 도출
- **Mom Test:** 학습자는 행·열만 맞춘 뒤 대각선을 빠뜨리기 쉽고, 「뭔가 빠진 느낌」과 10~20초 재검산으로 문제를 발견함
- **목표:** 직관에 의존하지 않고 **명시적 검증·판정**으로 완료 여부를 알려 준다

---

## 2. 문제 정의

### 2.1 마방진 규칙

| 규칙 | 설명 |
|------|------|
| 격자 | 4×4 |
| 숫자 | 1~16, 각 1회 |
| 마법합 | 모든 행(4) + 열(4) + 대각선(2) = **34** |
| 입력 | 14칸 채워짐 + **2칸 0(빈칸)** |
| 출력 | 빈칸 좌표, 채울 값, 전체 검증 결과 |

### 2.2 예시 (v0 기본 테스트 데이터)

```
 16   3   2  13
  5  10  11   0   → 8
  9   6   0  12   → 7
  4  15  14   1
```

정답: (1,3)=8, (2,2)=7

### 2.3 진짜 문제 (Mom Test)

> 행·열만 맞으면 거의 끝난 것처럼 느껴지는데, 대각선을 빼먹었는지는 「뭔가 빠진 느낌」에 의존하고, 그때마다 직접 재검산·값 수정 비용이 든다.

### 2.4 표면 문제 (범위 밖 — v0에서 직접 해결하지 않음)

「풀이/검증 프로그램을 만든다」는 기능 나열. v0는 **판정 명확성**과 **실패조건 리포트**에 집중.

## 4. 목표 및 성공 기준

### 4.1 제품 목표 (v0)

1. 빈칸 2곳 위치를 식별한다
2. 남은 숫자로 빈칸 값을 계산·배치한다
3. **10개 선분**(4행+4열+2대각선) + 숫자 집합을 검증한다
4. 완료 오인 실패조건(F1~F3) 발생 시 **어떤 조건·선분**이 실패했는지 반환한다

### 4.2 성공 기준 (측정 가능)

| ID | 기준 |
|----|------|
| SC-1 | 예시 격자 입력 시 빈칸 (1,3)=8, (2,2)=7 도출 |
| SC-2 | 행·열만 34이고 대각선 불일치인 격자 → **미완료** + 대각선 실패 표시 (F1) |
| SC-3 | 10선분 중 1개라도 ≠34 → 실패 선분 목록 반환 (F2) |
| SC-4 | 0(빈칸) 잔존 → **미완료** + 빈칸 좌표 반환 (F3) |
| SC-5 | 1~16 중복/누락 → **미완료** + 집합 오류 반환 (F4) |

## 6. 기능 요구사항

### 6.1 Entity

| ID | 요구사항 |
|----|----------|
| E-1 | `MagicSquare`: 4×4 `Cell` 배열, `MAGIC_SUM=34` |
| E-2 | `Cell`: `value`, `row`, `col`, `state` (`empty` \| `filled`) |
| E-3 | `SolveResult`: `blank_positions[]`, `filled_values[]`, `is_complete`, `failure_codes[]`, `failed_lines[]` |

### 6.2 Control

| ID | 요구사항 |
|----|----------|
| C-1 | `MissingFinder`: 값이 0인 칸 좌표 반환 (정확히 2개) |
| C-2 | `Solver`: 행/열 합 34로부터 빈칸 후보 값 계산; 1~16 미사용 숫자와 대조 |
| C-3 | `SquareValidator`: 10선분 합 검사, F1~F4 판정, 실패 상세 반환 |

### 6.3 Boundary

| ID | 요구사항 |
|----|----------|
| B-1 | `GridUI`: 4×4 격자 텍스트/간단 UI 표시 |
| B-2 | `InputHandler`: 초기 격자 수신 (파일·CLI·리터럴) |
| B-3 | `ResultDisplay`: 완료/미완료, 실패조건 코드, 실패 선분(예: `diag_main`, `row_2`) 출력 |

### 6.4 비기능 (v0)

| ID | 요구사항 |
|----|----------|
| NF-1 | Python 3.x, pytest로 SC-1~SC-5 검증 가능 |
| NF-2 | ECB 패키지/모듈 분리 (`entity`, `control`, `boundary`) |

## 7. 사용자 시나리오

### US-1: 예시 문제 풀기

1. 학습자가 예시 4×4 격자(빈칸 2) 입력
2. `MissingFinder`가 빈칸 2곳 표시
3. `Solver`가 8, 7 제안
4. `SquareValidator`가 10선분 + 숫자 집합 OK → **완료**

### US-2: 대각선 누락 오판 (Mom Test 재현)

1. 학습자가 행·열만 34로 맞춘 격자 제출
2. `SquareValidator`가 대각선 불일치 감지 → **F1**, `failed_lines`에 대각선 포함
3. `ResultDisplay`가 「대각선 미충족」 표시 — 「뭔가 빠진 느낌」 대체

### US-3: 값 수정 후 재검증

1. 잘못된 값 입력
2. `SquareValidator` → F4 또는 선분 실패
3. 학습자가 값 수정
4. 재검증 → 완료 또는 남은 실패 표시

## 8. 범위

- 4×4, 빈칸 2, 1~16, 합 34
- ECB 클래스 스keleton + 핵심 Control 로직
