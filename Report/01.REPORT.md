## 1. 요약

Rob Fitzpatrick Mom Test 스타일로 4×4 부분 마방진을 손으로/코드로 다루는 **학습자 페르소나** 인터뷰를 진행했다. 어제 처음 풀어본 경험(빈칸 2개, 행·열 합 맞춤, 대각선 1개 누락)을 중심으로 과거 행동·비용·판정 과정을 추궁했고, 인터뷰 종료 시 표면 문제·진짜 문제·Mom Test 증거 3줄을 정리했다.

## 2. 핵심 결정·산출물

### 표면 문제 (잘못된 정의)
「4×4 부분 마방진 풀이/검증 프로그램을 만든다」

### 진짜 문제 (한 문장)
행·열만 맞으면 거의 끝난 것처럼 느껴지는데, 대각선을 빼먹었는지는 **「뭔가 빠진 느낌」**이 들어야 알아차리고, 그때마다 **직접 다시 검산·값 수정**하는 비용이 든다.

### Mom Test 증거 3줄
- 「행과 열만 맞았는데, 뭔가 빠진 느낌이더라고.」
- 「중간에 이상해서 다시 확인해보았을 때 알았어.」
- 「10초에서 20초 사이였던 거 같아. 검산하는데 이 시간을 사용했어.」

### 인터뷰에서 드러난 맥락
- **첫 시도**: 어제가 처음, 별다른 계기 없이 심심해서 풀어봄
- **발견 경로**: 행·열은 맞았으나 직관적으로 빠진 느낌 → 대각선 확인 → 잘못된 값 인지 → 빈칸 지우고 변경
- **추가 비용**: 재검산·수정에 약 10~20초 (검산 시간)
